# 모바일 셸 스펙 (합의본)

모바일 UI는 코드 작성 전에 배치·규약을 이 문서로 합의하고, 합의된 범위만 구현한다.
이 문서는 1차(셸 = 전역 골격) 합의본이다. 각 모드 내부·설정 다이얼로그·오버레이류는
다음 차수에서 별도 합의한다.

## 디자인 규약 — 데스크톱 UI 리버스 엔지니어링 결과

모바일 컴포넌트는 아래 규약을 그대로 따른다. 신규 값(색·크기·곡선) 발명 금지.

**색.** 시맨틱 토큰만 사용: `paper`(바탕) / `surface`(패널) / `surface-2`(호버·칩) /
`ink`(본문) / `muted`(보조) / `faint`(희미) / `line`(경계) / `accent`(강조) /
`accent-soft`(선택 배경) / `danger`. hex 하드코딩 금지 — 테마 프리셋이
`buildWhimsTokens()`로 전 토큰을 갈아끼우므로 (theme-presets.ts), 토큰만 쓰면
모든 테마·라이트/다크에서 자동으로 옳다.

**타이포.** UI는 Pretendard Variable, 숫자·수치는 `font-mono`(JetBrains Mono).
텍스트 크기는 `text-[13px]` 형태의 px 리터럴만 사용(10~16px 스케일) —
main.css의 속성 선택자가 `--ui-scale`(ui_size 설정)로 일괄 배율하므로,
이 문법을 벗어나면 사용자 UI 크기 설정이 먹지 않는다.

**모서리.** 기본 `--radius` 8px. 버튼·칩·입력 = `rounded-md`, 카드·패널 =
`rounded-lg`/`rounded-xl`, 다이얼로그 = `rounded-2xl`, 원형 = `rounded-full`.

**컴포넌트.** 버튼은 `ui/button.tsx` cva 변형만 사용 — `default`(테두리+surface) /
`accent`(채움, 주 동작 1개) / `ghost`(아이콘·보조) / `danger`. 크기 sm h-7 / md h-8 /
lg h-10 / icon size-8. 아이콘은 lucide 13~16px.

**모션.** 곡선은 단일 표준 `[0.22, 1, 0.36, 1]`, 시간은 패널 신축 0.22s ·
소요소 0.18s. 등장/퇴장은 motion/react `AnimatePresence`.

**오버레이.** `z-50` + `bg-black/50 backdrop-blur-sm` 딤, 콘텐츠는
`bg-surface border-line shadow-2xl`. (ui/dialog.tsx와 동일)

**상태.** 호버 `bg-surface-2`, 선택(활성) `accent-soft + text-accent`
(PageNav 활성 표현과 동일), 비활성 `opacity-50`.

**터치(모바일 추가 규약).** 탭 타깃 최소 44×44px(시각 크기는 규약대로,
히트 영역만 확장). 호버 전용 노출은 `@media (hover: none)`에서 상시 노출로 전환.

## 셸 배치 (합의: 통합안 A)

원칙 두 가지.
- **가장자리 주인 규칙**: 화면 가장자리마다 상주 요소는 하나. 하단 = 생성 바(단독),
  상단 = 정보·내비 바(단독). 프롬프트 시트·히스토리 드로어는 상주하지 않고
  펼칠 때만 공간을 차지한다.
- **데스크톱 위치 대응**: 같을 수 있다면 데스크톱과 같은 위치에 — 사용자가 위치
  학습을 다시 하지 않게 한다.

| 요소 | 데스크톱 | 모바일 | 대응 |
|---|---|---|---|
| Anlas 잔액·소모 칩 | 타이틀바 좌측 | 상단 바 좌측 | 동일 |
| 모드 내비(메인·씬·디렉터·라이브러리·웹) | 타이틀바 중앙 PageNav | 상단 바 중앙(아이콘) | 동일 |
| 설정 버튼 | 타이틀바 우측 | 상단 바 우측 | 동일 |
| 테마 토글·업데이트 버튼 | 타이틀바 좌측부 | 상단 바 좌측(공간 시) → 없으면 설정 안 | 준동일 |
| 프롬프트 패널 | 좌측 사이드 패널 | 하단 시트(신축) | 이동 |
| 생성 바(파라미터·수량·생성) | 프롬프트 패널 하단 | 화면 하단 고정 | 동일(하단) |
| 히스토리 | 우측 사이드 패널 | 우측 드로어(생성 바 히스토리 버튼으로) | 동일(우측) |

### 상단 바
좌측부터: Anlas 칩(잔액 + 예상 소모, 데스크톱 `AnlasChips` 재사용) → (여유 시
테마 토글·업데이트 버튼) → 중앙 모드 아이콘 내비(hiddenPages 반영, 활성 =
accent-soft, 데스크톱 PageNav와 같은 아이콘) → 우측 설정 버튼. 창 컨트롤(─□✕)은
웹/모바일에 없음.

### 중앙
현재 모드 콘텐츠. 메인 모드 = 미리보기(PreviewPane).

### 프롬프트 시트 (하단 시트, 3스냅)
데스크톱 좌측 패널(PromptPanel) 내용을 세로 시트로. 스냅 3단:
- **닫힘**: 핸들(▲ 프롬프트)만 생성 바 위에 노출.
- **중간**: 핸들 **탭** 시 — 기본은 프롬프트 영역이 보이는 고정 중간 높이.
  설정 `ui_mobile_sheet_thirds`("프롬프트 3분할") 켜면 가변(3분할) 높이로 열림.
- **전체**: 핸들을 **위로 풀링**하면 전체 열기(상단 바 아래까지).
어느 스냅에서도 생성 바는 시트 아래 그대로 고정(불변 조건). 밖(미리보기) 터치
또는 아래로 풀링 시 닫힘. 설정 키는 기존 `settings:get/set` 임의 키 — 새 IPC 채널 0개.

### 생성 바 (하단 고정 — 메인 모드 소유)
데스크톱 프롬프트 패널 하단 바와 동형 + 히스토리 버튼:

```
[⚙ 파라미터] [− n + 예약 수량] [   생성 (accent, flex-1)   ] [🕘 히스토리]
```

- 파라미터: 데스크톱과 동일하게 ParamsDialog 열기 (ghost icon).
- 예약 수량: 데스크톱 batchCount 스테퍼 그대로(− 입력 +, font-mono).
- 생성: 데스크톱과 동일한 3상태 — 생성 / 씬 생성(n장) / 취소(danger, 생성 중).
- 히스토리: 우측 드로어 토글 (ghost icon).

### 히스토리 드로어 (우측 오버레이)
생성 바의 히스토리 버튼 탭 → 우측에서 드로어 슬라이드 인(HistoryPanel 재사용,
폭 240px 상당·최대 화면 75%). 딤 오버레이, **드로어 밖 터치 또는 히스토리 버튼
재탭으로 닫힘**. 상주하지 않음(가장자리 주인 규칙).

### 다른 모드
상단 바는 전 모드 공통 고정. 하단 바는 모드가 소유 — 메인 = 생성 바,
씬·디렉터·라이브러리·웹의 하단 바 구성은 **다음 차수 합의 대상**(합의 전까지
해당 모드는 하단 바 없이 콘텐츠만).

## 구현 형태 (경계)

- 신규 코드는 `src/renderer/src/mobile/` 폴더에만. 데스크톱 경로에서 import 금지.
- 진입은 App.tsx의 isMobile 분기(수 줄)만. isMobile=false면 기존 트리 그대로 —
  데스크톱 번들에 대한 동작 변화 없음.
- isMobile 판정: `matchMedia(max-width)` + 설정 `ui_mobile`('auto'|'on'|'off')
  오버라이드. 기존 설정 채널 재사용, 새 IPC 채널 없음.
- PromptPanel·HistoryPanel·PreviewPane 등 기존 컴포넌트는 재사용이 원칙,
  수정이 필요하면 가산적 최소 수정(파일당 리뷰 한 화면 이내).
